9-1. 학습 유형 — 지도 vs 비지도 🔥

항목 지도 학습 (Supervised) 비지도 학습 (Unsupervised)
학습 데이터 입력 + 정답 레이블 입력만 (레이블 없음)
목적 새 입력의 정답 예측 데이터의 숨은 구조·패턴 발견
대표 과제 분류(스팸/정상), 회귀(가격 예측) 군집(고객 세분화), 차원 축소, 이상 탐지
대표 알고리즘 K-NN, 결정 트리, SVM, 선형·로지스틱 회귀, 신경망 K-means, 계층적 군집, DBSCAN, PCA
평가 정답과 비교(정확도·정밀도 등) 정답이 없어 내부 지표(실루엣 등)
단점 레이블링 비용 큼 결과 해석이 어려움
  • △ 강화 학습: 환경과 상호작용하며 보상을 최대화하는 행동 정책 학습 (게임, 로봇)
  • ⚠️ 함정: K-NN = 지도(분류), K-means = 비지도(군집). 이름만 비슷하다.

9-2. K-NN (K-Nearest Neighbor) 🔥 🧮 ✍️

정의: 새 데이터와 가장 가까운 K개의 학습 데이터를 찾아 다수결로 클래스를 정하는 분류 알고리즘. 학습 단계에서 모델을 만들지 않고 데이터를 저장만 했다가 예측 시 계산 → 게으른 학습(Lazy Learning).

절차: ① 새 데이터와 모든 학습 데이터의 거리 계산
      ② 거리 오름차순 정렬
      ③ 가까운 K개 선택 → ④ 다수결

유클리드 거리  d = √((x2 − x1)² + (y2 − y1)²)
맨해튼 거리    d = |x2 − x1| + |y2 − y1|

(설명용 예) 새 점 (3, 4)
  P(0, 0): √(9 + 16)   = √25  = 5
  Q(6, 8): √(9 + 16)   = 5
  R(3, 14): √(0 + 100) = 10
  근호 정리: √1000 = √(100 × 10) = 10√10
  • K는 홀수로 (이진 분류에서 동점 방지), K에 따라 결과가 바뀐다 (작으면 노이즈에 민감, 크면 경계가 뭉개짐)
  • 특성 단위가 다르면(키 cm vs 몸무게 kg) 정규화 필요 — 큰 단위 특성이 거리를 지배
  • 단점: 예측 시 모든 거리 계산(느림), 차원의 저주(차원이 높으면 거리가 다 비슷해짐)

C언어 유클리드 거리 (math.h의 sqrt, pow):

double dist = sqrt(pow(x2 - x1, 2) + pow(y2 - y1, 2));

정수 좌표라도 pow가 double을 반환하므로 형변환 문제는 없다. ^는 C에서 XOR이지 거듭제곱이 아니다 — 함정.

K-NN 풀이 4단 🔥 🧮

  1. 신규 데이터와 각 데이터의 거리 계산 (유클리드 √(Δx² + Δy²))
  2. 오름차순 정렬표 작성 (√값은 제곱값으로 비교해도 됨: √125 < √225 < √250)
  3. 상위 K개 라벨 다수결
  4. 결론
  • 🔥 K = 가까운 이웃의 개수(반지름 아님). 그림의 원은 K번째 이웃까지의 거리를 반지름으로 그린 것.
  • 시험지 그래프는 가로·세로 눈금이 다를 수 있어 눈으로 본 거리 ≠ 실제 거리 → 반드시 계산으로 판정.

9-3. K-means 군집화 ⭐

① k개의 중심(centroid)을 초기화
② 각 데이터를 가장 가까운 중심의 군집에 할당
③ 각 군집의 평균으로 중심을 다시 계산
④ 중심이 변하지 않을 때까지 ②~③ 반복

K-means의 한계 (서술 3가지 이상)

  1. k를 미리 정해야 한다 — 적절한 군집 수를 모르면 결과가 왜곡 (엘보우 기법·실루엣 계수로 보완)
  2. 초기 중심에 민감하다 — 초기값에 따라 지역 최적해로 수렴, 데이터가 없는 곳에 중심이 놓이면 빈 군집 발생 (K-means++ 초기화로 완화)
  3. 이상치(Outlier)에 민감 — 평균을 쓰므로 이상치 하나가 중심을 끌어당김 (K-medoids로 보완)
  4. 구형·비슷한 크기의 군집을 가정 — 길쭉하거나 밀도가 다른 군집은 분리 못함 (DBSCAN으로 보완)
  5. 특성 스케일 차이에 영향을 받음 → 정규화 필요

9-4. 분류 성능 평가 — 혼동 행렬 🔥 🧮

실제 Positive 실제 Negative
예측 Positive TP (맞게 양성) FP (틀리게 양성)
예측 Negative FN (틀리게 음성) TN (맞게 음성) 
정확도 (Accuracy)  = (TP + TN) / 전체
정밀도 (Precision) = TP / (TP + FP)   "양성이라 예측한 것 중 진짜 양성"
재현율 (Recall)    = TP / (TP + FN)   "진짜 양성 중 잡아낸 것"
F1                 = 2 × P × R / (P + R)

(설명용 예) TP=45, FP=5, FN=15, TN=35 (전체 100)
  정확도 = 80/100 = 80%   정밀도 = 45/50 = 90%   재현율 = 45/60 = 75%

⚠️ 함정: 표의 행이 예측인지 실제인지 먼저 확인한다(문제마다 다름). 답을 %로 요구하면 반드시 % 표기. 언제 무엇을 중시? 스팸 필터는 정상 메일을 스팸으로 버리면 안 되므로 정밀도, 암 진단·사기 탐지는 놓치면 안 되므로 재현율. 불균형 데이터(양성 1%)에서는 정확도가 무의미 → F1 사용.

9-5. 경사하강법 · 신경망 🔥 🧮

경사하강법 (Gradient Descent)

W ← W − η · ∂Loss/∂W        b ← b − η · ∂Loss/∂b
손실 함수(MSE) Loss = (1/n) Σ (예측값 − 실제값)²
→ 기울기의 반대 방향으로 조금씩 이동해 손실의 최솟값을 찾는다
학습률 η 문제점
너무 크면 최솟값을 지나쳐 좌우로 진동하거나 손실이 오히려 커지며 발산
너무 작으면 수렴이 매우 느림(학습 시간·비용 증가), 지역 최솟값·안장점에 갇히기 쉬움

지역 최솟값(Local Minimum)을 벗어나 전역 최솟값을 찾을 확률을 높이는 방법

  1. 모멘텀(Momentum) — 이전 이동 방향의 관성을 더해 작은 언덕을 넘음
  2. 적응형 옵티마이저(Adam, RMSProp) — 파라미터마다 학습률을 자동 조정
  3. 확률적 경사하강법(SGD)·미니배치 — 일부 데이터로 기울기를 계산해 생기는 노이즈가 웅덩이를 탈출시킴
  4. 여러 초기값으로 반복 학습(랜덤 재시작) 후 가장 낮은 손실 선택
  5. 학습률 스케줄링 — 처음엔 크게, 점점 작게 (Warm restart로 주기적으로 다시 크게)

과적합 vs 과소적합 🔥

과적합 (Overfitting) 과소적합 (Underfitting)
정의 학습 데이터의 노이즈까지 외워 새 데이터에 일반화 실패 모델이 너무 단순해 데이터의 패턴조차 못 잡음
증상 훈련 오차 ↓, 검증 오차 ↑ 훈련·검증 오차 모두 높음
원인 모델이 너무 복잡, 데이터 부족, 과도한 학습 모델이 단순, 특성 부족, 학습 부족
해결 데이터 추가·증강, 정규화(L1/L2), 드롭아웃, 조기 종료, 모델 단순화, 교차 검증 모델 복잡도·특성 증가, 학습 더 진행, 정규화 완화

퍼셉트론과 순전파 계산 🧮

퍼셉트론: z = Σ wᵢxᵢ + b  →  출력 = f(z)
ReLU:     f(z) = max(0, z)     (z < 0 이면 0, z ≥ 0 이면 z)

(설명용 예) 은닉 2개 + 출력 1개, 입력 (x1, x2) = (1, 0)
  은닉1: z = 3·1 + (−2)·0 + (−1) = 2   → ReLU → 2
  은닉2: z = (−4)·1 + 1·0 + 2   = −2  → ReLU → 0
  출력 : z = 1·2 + (−3)·0 + 1   = 3   → ReLU → 3

풀이 습관: 층별 표(입력 / 가중합 z / 활성화 후 값)로 쓴다. 음수가 나오면 ReLU에서 0이 되는 것을 놓치지 말 것.

활성화 함수 범위 특징
Sigmoid 0~1 미분 최댓값 0.25 → 깊어지면 기울기 소실
tanh −1~1 0 중심, 여전히 소실
ReLU 0~∞ 양수 구간 미분 1 → 기울기 소실 완화, 계산 빠름 (단점: Dying ReLU)

역전파 (Backpropagation) 🔥

정의: 출력층의 오차를 연쇄 법칙(Chain Rule)으로 입력층 방향으로 거꾸로 전파하며 각 가중치가 오차에 기여한 정도(기울기)를 계산하고, 경사하강법으로 가중치를 갱신하는 신경망 학습 알고리즘.

① 순전파: 입력 → 은닉층 → 출력 계산
② 손실 계산: 예측과 정답의 차이 (MSE, 교차 엔트로피)
③ 역전파: ∂Loss/∂w = ∂Loss/∂출력 × ∂출력/∂z × ∂z/∂w  (출력층 → 입력층 방향)
④ 갱신: w ← w − η · ∂Loss/∂w
⑤ ①~④를 반복 (에폭)

핵심 장점: 모든 가중치의 기울기를 한 번의 역방향 계산으로 효율적으로 구한다(중간 결과 재사용).

퍼셉트론 계산 순서 · 국소 최솟값 탈출 🔥

  • 계산 순서: ① z = Σ(w·x) + b — 음수 항도 그대로 더함 ② 출력 = f(z) — 활성화 함수는 뉴런당 한 번, 합 뒤에. 은닉층 출력은 h로 이름 붙여 다음 층 입력으로 → 표는 입력 | z | h | y 열로.
국소 최솟값 탈출 방법 원리
SGD·미니배치 일부 데이터로 구한 기울기의 노이즈로 얕은 골짜기를 벗어남
모멘텀 이전 이동 방향을 관성처럼 유지해 작은 언덕을 넘음
Adam·RMSProp 파라미터별 적응적 학습률 + 모멘텀
여러 초기값 재시작 출발점을 바꿔 여러 번 학습 후 최선 선택
학습률 스케줄·Warm Restart 주기적으로 큰 학습률로 넓게 탐색

9-6. RNN과 기울기 소실 ⭐

RNN(순환 신경망): 이전 시점의 은닉 상태 hₜ₋₁을 현재 입력과 함께 사용해 순서가 있는 데이터(문장·시계열)를 처리. 모든 시점이 같은 가중치 W를 공유한다.

기울기 소실 (Vanishing Gradient) 정의: 역전파 과정에서 기울기가 앞쪽 층(이전 시점)으로 갈수록 0에 가까워져, 앞부분 가중치가 거의 갱신되지 않아 학습이 안 되는 문제.

RNN에서 발생하는 이유

  1. 시간 축으로 펼친 역전파(BPTT)에서 기울기가 시점 수만큼 연쇄 곱셈된다
  2. 곱해지는 항에 시그모이드의 미분값(최대 0.25 < 1)과 같은 가중치 W가 반복 포함된다
  3. 1보다 작은 수를 수십 번 곱하면 지수적으로 0에 수렴 → 먼 과거 입력의 영향을 학습 못 함 = 장기 의존성(Long-term Dependency) 문제
∂L/∂h₁ = ∂L/∂h_T × Π (σ'(·) × W)    σ' ≤ 0.25
         예) 0.25 를 10번 곱하면 ≈ 0.00000095
  • 해결: LSTM·GRU(게이트와 셀 상태로 기울기 경로를 덧셈으로 유지), ReLU 계열 활성화, 적절한 가중치 초기화, 잔차 연결
  • 반대 현상: 기울기 폭주(Exploding) → Gradient Clipping

9-7. 자연어 처리 · LLM 🔥

정규 표현식 (Regular Expression) ⭐

기호 의미 예
? 앞 문자 0회 또는 1회 colou?r → color, colour
* 앞 문자 0회 이상 wo*w → ww, wow, wooow
+ 앞 문자 1회 이상 wo+w → wow, wooow (ww 불가)
() 그룹 ba(na)+na → banana, bananana
△ . [] ^ $ \| {n,m} 임의 1문자 / 문자 집합 / 시작 / 끝 / 또는 / n~m회

매칭 판정 요령: 패턴을 기호 단위로 쪼개 문자열 앞에서부터 대응시킨다. ?·*는 0회도 되므로 건너뛰는 경우까지 시도하고, 끝까지 대응시켰을 때 남는 문자나 부족한 필수 문자(+ 대상, 일반 문자)가 있으면 불일치.

(설명용 예) 패턴 x?yz*y+
  "yyy"   : x? 0회, y, z* 0회, y+ = "yy"      → 매칭
  "xyzzy" : x, y, z* = "zz", y+ = "y"        → 매칭
  "xyz"   : x, y, z* = "z", y+ 필요한데 끝    → 불일치

BoW (Bag-of-Words) ⭐

  • 정의: 문서를 단어 출현 빈도의 벡터로 표현하는 전통적 텍스트 마이닝 기법. 단어를 가방에 쏟아 넣듯 순서·문법·문맥을 무시하고 개수만 센다.
  • 절차: 전체 문서에서 단어 사전 구축 → 문서마다 각 단어 빈도를 벡터로
  • 장점: 단순, 문서 분류·스팸 필터에 효과적 / 한계: 어순·문맥 손실("개가 사람을 물었다" = "사람이 개를 물었다"), 사전 크기만큼 희소(sparse)한 고차원 벡터, 동의어 구분 불가
  • 발전: TF-IDF(흔한 단어 가중치↓) → Word2Vec 임베딩 → 트랜스포머 문맥 임베딩

사전학습 vs 미세조정 🔥

사전학습 (Pre-training) 미세조정 (Fine-tuning)

환각 (Hallucination) · RAG 🔥

  • 환각: LLM이 사실이 아니거나 근거 없는 내용을 그럴듯하게 생성하는 현상. 원인: 다음 단어를 확률적으로 생성할 뿐 사실 검증을 하지 않음, 학습 데이터의 한계·시점(최신 정보 없음)
  • RAG (Retrieval-Augmented Generation, 검색 증강 생성): 답을 생성하기 전에 외부 지식 저장소에서 관련 문서를 검색해 프롬프트에 근거로 넣은 뒤 생성하는 방법
질문 → ① 검색(Retrieval): 벡터 DB에서 질문과 유사한 문서 조각 검색 (임베딩 유사도)
     → ② 증강(Augmentation): 검색 결과를 프롬프트에 "근거"로 추가
     → ③ 생성(Generation): LLM이 근거를 바탕으로 답변 (+ 출처 제시)
  • 효과: 환각 감소, 최신·내부 정보 반영(재학습 없이 문서만 갱신), 근거 출처 제시로 신뢰성↑ / 한계: 검색 품질에 의존, 지연 증가
  • 금융 연결: 금융사 내부 규정·약관 질의응답에 RAG가 쓰이고, 감독 관점에서는 AI 산출물의 설명 가능성·근거 추적이 중요

결정 트리의 분할 기준

  • 엔트로피 H = −Σ pᵢ log₂ pᵢ, 지니 불순도 G = 1 − Σ pᵢ²
  • 정보 이득 = 분할 전 엔트로피 − 분할 후 엔트로피의 가중 평균

예제. 14개 표본 중 긍정 9개, 부정 5개인 노드의 엔트로피와 지니 불순도는?

풀이
  • 엔트로피 = −(9/14)log₂(9/14) − (5/14)log₂(5/14) = 0.410 + 0.530 = 0.940
  • 지니 = 1 − (9/14)² − (5/14)² = 1 − 0.413 − 0.128 = 0.459
  • 한 클래스만 있으면 둘 다 0(완전히 순수), 반반이면 엔트로피 1, 지니 0.5(가장 불순).

CNN (합성곱 신경망)

구성역할
합성곱 층필터가 이미지를 훑으며 국소 특징 추출. 가중치 공유로 파라미터 절감
풀링 층공간 크기 축소, 작은 이동에 대한 불변성
완전 연결 층추출한 특징으로 분류

출력 크기 = (입력 − 필터 + 2 × 패딩) / 스트라이드 + 1

예제. 32×32×3 이미지에 5×5 필터 6개(패딩 0, 스트라이드 1)를 적용하고 2×2 최대 풀링(스트라이드 2)을 한다. 출력 크기와 합성곱 층의 파라미터 수는?

풀이
  • 합성곱 출력: (32 − 5 + 0) / 1 + 1 = 28 → 28×28×6
  • 풀링 출력: 28 / 2 = 14 → 14×14×6
  • 파라미터: 필터 하나가 5×5×3 = 75 개 가중치 + 편향 1 = 76. 필터 6개 → 456개
  • 풀링 층에는 학습 파라미터가 없다.
  • 같은 입력을 완전 연결 층으로 처리하면 뉴런 하나당 32×32×3 = 3,072 개 가중치가 필요하다. 가중치 공유의 효과다.
  • 전이 학습: 대규모 데이터로 학습한 모델의 앞쪽 층(일반적인 특징)을 그대로 두고 뒤쪽만 내 데이터로 학습. 적은 데이터로 높은 성능.

9-11. Transformer 🔥

왜 나왔나

RNN 은 토큰을 순서대로 처리한다. → 병렬화가 안 되고, 멀리 떨어진 토큰의 정보가 희미해진다(장기 의존성, → RNN과 기울기 소실).

→ 어텐션만으로 모든 토큰이 서로를 직접 참조하게 하자. ("Attention Is All You Need", 2017)

셀프 어텐션

Attention(Q, K, V) = softmax(Q·Kᵀ / √dₖ) · V

  1. 각 토큰 임베딩에서 질의(Q), 키(K), 값(V) 벡터를 만든다.
  2. 내 Q 와 모든 토큰의 K 를 내적해 관련도 점수를 구한다.
  3. √dₖ 로 나누고(값이 커져 소프트맥스 기울기가 사라지는 것을 방지) 소프트맥스로 가중치를 만든다.
  4. 그 가중치로 V 를 가중 합한 것이 그 토큰의 새 표현이다.
  • "그것은 너무 피곤해서 길을 건너지 못했다"에서 "그것"이 "동물"을 가리킨다는 것을 어텐션 가중치가 학습한다.
  • 멀티 헤드 어텐션: 어텐션을 여러 개 병렬로 두어 서로 다른 관계(문법, 지시 대상, 의미)를 동시에 본다.
  • 위치 인코딩: 어텐션은 순서를 모른다(집합처럼 처리). 그래서 토큰 임베딩에 위치 정보를 더한다.
  • 복잡도: 시퀀스 길이 n 에 대해 O(n²) — 모든 쌍을 본다. 긴 문맥이 비싼 이유다.

RAG (검색 증강 생성)

질문과 관련된 문서를 검색해 프롬프트에 넣어 답하게 한다. 환각의 기본 개념은 → 환각 · RAG

[색인 단계]  문서 → 청킹 → 임베딩 → 벡터 DB 저장
[질의 단계]  질문 → 임베딩 → 유사도 검색 (Top-K) → 재순위화 → 프롬프트에 삽입 → LLM 생성 → 답변 + 출처
단계핵심 결정문제가 되는 경우
청킹조각의 크기·겹침, 문단·제목 단위 분할너무 작으면 문맥 손실, 너무 크면 잡음
임베딩의미를 벡터로 바꾸는 모델 선택도메인 용어·한국어 성능
검색벡터 검색 + 키워드 검색(BM25) 을 합친 하이브리드벡터만 쓰면 고유명사·코드·숫자에 약함
재순위화후보를 정밀 모델로 다시 정렬지연 증가
생성"주어진 문서에 근거해서만 답하라", 출처 표기검색이 틀리면 답도 틀림
  • 임베딩: 의미가 비슷한 텍스트가 가까운 벡터가 되도록 한 표현. 유사도는 주로 코사인 유사도.
  • 벡터 DB / ANN: 수백만 벡터에서 정확한 최근접을 찾으면 느리다. → 근사 최근접 탐색(HNSW 그래프, IVF 군집)으로 약간의 정확도를 내주고 속도를 얻는다.
  • 평가: 검색 품질(재현율, 순위)과 생성 품질(근거 충실도, 답변 관련성)을 따로 본다.

에이전트 · 도구 호출

  • 도구 호출(Function Calling): 모델이 "이 함수를 이 인자로 호출해 달라"는 구조화된 요청을 내고, 애플리케이션이 실행해 결과를 다시 모델에 준다. 모델이 직접 실행하는 것이 아니다.
  • 에이전트: 목표를 받아 계획 → 도구 호출 → 결과 관찰 → 다음 행동을 스스로 반복하는 시스템.
  • MCP (Model Context Protocol): 모델과 외부 도구·데이터를 연결하는 표준 규약. 도구를 한 번 만들어 여러 모델·애플리케이션에서 쓴다.
  • 위험: 단계가 많을수록 오류가 누적되고 비용·지연이 커진다. 되돌릴 수 없는 행동(송금, 삭제, 발송)에는 사람의 승인을 둔다.
