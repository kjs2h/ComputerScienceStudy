10-1. Java 접근 제어자 (Access Modifier) 🔥

접근 제어자 같은 클래스 같은 패키지 다른 패키지의 자식 클래스 전체
public ✅ ✅ ✅ ✅
protected ✅ ✅ ✅ ❌
default (키워드 없음) ✅ ✅ ❌ ❌
private ✅ ❌ ❌ ❌ 
영향 범위가 넓은 순서:  public  >  protected  >  default  >  private
  • public: 어디서나 접근 / protected: 같은 패키지 + 상속받은 자식 클래스(다른 패키지여도) / default: 아무것도 안 쓰면 적용, 같은 패키지만 / private: 선언한 클래스 내부만
  • 연결: 캡슐화·정보 은닉(7-3) — 필드는 private, 접근은 public getter/setter
  • ⚠️ 함정: default는 키워드를 쓰는 게 아니라 생략하는 것 (인터페이스의 default 메서드와 별개). 클래스(외부)에는 public과 default만 붙일 수 있다.

10-3. C 자료형 함정 — unsigned 🔥

unsigned int로 i >= 0 조건을 쓰면 항상 참 → 무한 루프. 0에서 1을 빼면 최댓값(2³² − 1 = 4,294,967,295)으로 순환한다. 자세한 실행 흐름은 4-4 데이터 표현의 unsigned 언더플로 참고.

C 함정 모음 ⭐ 내용
^ 거듭제곱이 아니라 XOR → 제곱은 pow(x, 2) 또는 x * x
정수 나눗셈 5 / 2 = 2 (소수점 버림) → 5.0 / 2
전위 vs 후위 --i는 감소 후 사용, i--는 사용 후 감소
signed ↔ unsigned 비교 -1 < 1u 는 거짓 (−1이 unsigned로 변환되어 매우 큰 수)

10-6. 메모리 모델 · 인자 전달 · 가비지 컬렉션 🔥

스택 vs 힙

구분스택힙
저장지역 변수, 매개변수, 복귀 주소동적으로 할당한 객체
할당·해제함수 호출·반환 시 자동명시적(malloc/free) 또는 GC
속도매우 빠름 (포인터 이동)상대적으로 느림
크기작고 고정 (보통 수 MB)큼

오류스택 오버플로메모리 누수, 단편화

값 전달 vs 참조 전달

방식전달되는 것함수 안의 변경이 호출자에게
값에 의한 호출값의 복사본반영되지 않음
참조에 의한 호출변수 자체(별칭)반영됨

Java 는 언제나 값에 의한 호출이다. 객체를 넘기면 참조값(주소)의 복사본이 전달된다.

void change(int[] arr, int[] other) {
    arr[0] = 99;          // 같은 객체를 가리키므로 호출자에게 보인다
    other = new int[]{7}; // 복사된 참조를 다른 객체로 돌릴 뿐, 호출자에게 영향 없음
}

int[] a = {1}, b = {1};
change(a, b);
// a[0] == 99, b[0] == 1
  • C 는 값 전달만 있고 포인터를 넘겨 참조 전달을 흉내 낸다. C++ 은 참조(&)로 진짜 참조 전달을 지원한다.
  • Python 은 "객체 참조를 값으로 전달"한다. 리스트 같은 가변 객체를 수정하면 보이고, 매개변수에 새 객체를 대입하면 보이지 않는다. Java 와 같은 방식이다.

가비지 컬렉션

더 이상 도달할 수 없는 객체의 메모리를 자동으로 회수한다.

알고리즘방식장점단점
참조 계수참조 수가 0 이 되면 즉시 해제즉시 회수, 단순순환 참조를 회수 못 함, 계수 갱신 비용
표시-청소 (Mark-Sweep)루트에서 도달 가능한 객체를 표시, 나머지 해제순환 참조 처리단편화, 실행 멈춤
표시-압축 (Mark-Compact)청소 후 살아남은 객체를 한쪽으로 모음단편화 없음이동 비용
복사 (Copying)살아 있는 객체만 다른 영역으로 복사빠름, 단편화 없음메모리의 절반만 사용
세대별 (Generational)젊은 세대와 늙은 세대를 나눠 다르게 수집대부분의 객체는 금방 죽는다는 관찰을 활용구현 복잡
  • GC 루트: 스택의 지역 변수, 정적 변수, 활성 스레드 등. 여기서 참조를 따라가 닿는 객체가 "살아 있는" 객체다.
  • Stop-the-World (STW): GC 가 애플리케이션 스레드를 모두 멈추는 시간. 응답 지연의 원인이 된다.

10-8. C 포인터 · 메모리 🔥 ✍️

포인터와 배열

int a[5] = {10, 20, 30, 40, 50};
int *p = a;              // a 는 첫 원소의 주소로 변환된다 (&a[0])

printf("%d\n", *p);        // 10
printf("%d\n", *(p + 2));  // 30  — p + 2 는 주소를 2 × sizeof(int) 만큼 증가
printf("%d\n", p[3]);      // 40  — p[i] 는 *(p + i) 와 같다
printf("%d\n", *p++);      // 10  — 후위 증가: 현재 값을 쓴 뒤 p 가 다음 원소로
printf("%d\n", *p);        // 20
printf("%d\n", ++*p);      // 21  — p 가 가리키는 값을 1 증가
printf("%d\n", (*p)++);    // 21  — 값을 쓴 뒤 1 증가 → a[1] 은 22
식의미
*p++*(p++) — 값을 읽고 포인터를 증가
(*p)++값을 읽고 가리키는 값을 증가
*++p포인터를 먼저 증가시킨 뒤 값을 읽음
++*p가리키는 값을 먼저 증가시킨 뒤 읽음
  • sizeof(a) 는 배열 전체 크기(20), sizeof(p) 는 포인터 크기(64비트에서 8). 배열을 함수 인자로 넘기면 포인터가 되어 크기 정보를 잃는다.
  • 포인터끼리의 뺄셈은 원소 개수 차이다.
선언읽는 법
const int *p가리키는 값을 바꿀 수 없다 (포인터는 바꿀 수 있음)
int *const p포인터를 바꿀 수 없다 (값은 바꿀 수 있음)
int *p[3]포인터 3개의 배열
int (*p)[3]원소 3개짜리 배열을 가리키는 포인터
int (*f)(int)int 를 받아 int 를 돌려주는 함수의 포인터

문자열

char s1[] = "abc";     // 배열, 크기 4 ('\0' 포함), 수정 가능
char *s2  = "abc";     // 문자열 상수를 가리키는 포인터, 수정하면 정의되지 않은 동작

sizeof(s1);   // 4
strlen(s1);   // 3 — '\0' 은 세지 않는다

구조체 패딩 🧮

CPU 는 자료형 크기의 배수 주소에서 값을 읽는 것이 빠르다(정렬). 컴파일러는 멤버 사이에 빈 바이트를 넣어 정렬을 맞춘다.

예제. char 1바이트, int 4바이트일 때 두 구조체의 크기는?

struct A { char a; int b; char c; };
struct B { int b; char a; char c; };
풀이
  • struct A: a(1) + 패딩(3) + b(4) + c(1) + 끝 패딩(3) = 12바이트
  • struct B: b(4) + a(1) + c(1) + 끝 패딩(2) = 8바이트
  • 규칙: 각 멤버는 자기 크기의 배수 위치에서 시작하고, 구조체 전체 크기는 가장 큰 멤버 크기의 배수가 된다.
  • 큰 멤버부터 선언하면 패딩이 줄어든다.

얕은 복사 vs 깊은 복사

import copy

x[0].append(99)

print(d)   # [[1, 2], [3, 4]]

GIL · 병렬 처리

GIL(Global Interpreter Lock): CPython 에서 한 번에 한 스레드만 바이트코드를 실행하게 하는 락. 참조 계수 조작을 단순하고 안전하게 하려는 선택이다.

작업멀티스레딩대안
CPU 위주 (계산)효과 없음 (오히려 느려질 수 있음)multiprocessing, C 확장(NumPy)
I/O 위주 (네트워크, 파일)효과 있음 (대기 중 GIL 을 놓음)threading, asyncio
  • asyncio: 단일 스레드 이벤트 루프에서 await 지점마다 다른 코루틴으로 전환. 많은 I/O 를 적은 자원으로 처리한다.
  • Python 3.13 부터 GIL 을 끈 빌드(free-threaded)가 선택 사항으로 제공된다.

제너레이터 · 데코레이터 · 컴프리헨션

# 제너레이터: 값을 하나씩 만들어 내므로 메모리를 쓰지 않는다
def fib():
    a, b = 0, 1
    while True:
        yield a
        a, b = b, a + b

squares = (x * x for x in range(10**9))   # 제너레이터 표현식 — 즉시 계산하지 않음

# 데코레이터: 함수를 받아 기능을 덧붙인 함수를 돌려준다
import time, functools
def timed(fn):
    @functools.wraps(fn)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        try:
            return fn(*args, **kwargs)
        finally:
            print(fn.__name__, time.perf_counter() - start)
    return wrapper

# 컴프리헨션
evens = [x for x in range(10) if x % 2 == 0]
index = {name: i for i, name in enumerate(["a", "b"])}
  • *args 는 위치 인자 튜플, **kwargs 는 키워드 인자 딕셔너리.
  • with 문(컨텍스트 관리자)은 예외가 나도 자원 정리를 보장한다.
  • 메모리 관리: 참조 계수가 기본, 순환 참조는 세대별 GC 가 처리.
